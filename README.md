# odin-etch-a-sketch

A browser-based Etch-a-Sketch project created as part of The Odin Project Foundations course.

## About

This project creates a drawing grid using JavaScript and Flexbox. Users can draw by moving the mouse over the grid squares and can change the number of squares in the grid.

## Features

- Default 16x16 drawing grid
- Grid squares created using JavaScript
- Flexbox layout
- Draw by hovering over squares
- Change the grid size using a button
- Supports grid sizes up to 100x100
- Keeps the same sketchpad size when changing the grid
- Random RGB colors
- Progressive opacity effect
- Squares become more visible with each interaction

## Built With

- HTML
- CSS
- JavaScript

## How to Use

1. Open the webpage in your browser.
2. Move your mouse over the grid to draw.
3. Click the **Change Grid Size** button to create a new grid.
4. Enter a number from 1 to 100.
5. Move your mouse over the new grid to start drawing.
